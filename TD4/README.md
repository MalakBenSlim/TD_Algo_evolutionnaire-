# TD4 : Algorithmes génétiques, PSO et colonies de fourmis

Travaux dirigés (corrigés) du module d'optimisation / métaheuristiques.
Faculté des Sciences de Sfax, Université de Sfax.

## Contenu

| Exercice | Sujet | Dossier | Code |
|---|---|---|---|
| 1 | Théorème des schémas (algorithmes génétiques) | [`exercice1/`](exercice1/) | `schemas.py` |
| 3 | Optimisation par essaim de particules (PSO) | [`exercice3/`](exercice3/) | `pso.py` |
| 4 | Problème du sac à dos par colonie de fourmis (ACO) | [`exercice4/`](exercice4/) | `aco_sac_a_dos.py` |

Chaque dossier contient un `README.md` avec l'**énoncé**, la **correction détaillée** et le programme Python correspondant.

> L'exercice 2 du TD n'est pas traité dans ce dépôt.

## Prérequis

- Python 3.8 ou plus récent
- Aucune bibliothèque externe (uniquement la bibliothèque standard)

## Utilisation

```bash
git clone https://github.com/<votre-compte>/TD4-Metaheuristiques.git
cd TD4-Metaheuristiques

python exercice1/schemas.py
python exercice3/pso.py
python exercice4/aco_sac_a_dos.py
```
